# T5 — Training, Calibration, and Evaluation

## Goal

Produce reproducible model artifacts and honest, independent test reports.

## Dataset and split

- [ ] Freeze train, validation, and test manifests.
- [ ] Split by physical egg, source image, or capture session.
- [x] Add repeatable image/label, box-format, duplicate, and near-duplicate validation.
- [x] Check the current splits for exact and perceptual duplicate leakage.
- [x] Add sampled box-overlay previews and oversized-box reporting for visual review.
- [x] Resolve the detected duplicate leakage before freezing manifests by removing
  both source-conflicting detector pairs.
- [ ] Keep the test set untouched during model and threshold development.
- [x] Generate a detector manifest and validation report with annotation-source metadata.
- [ ] Record the final dataset version, label protocol, source, and imaging conditions.

## Damage model

- [x] Train from `data/damage/`.
- [x] Use balanced sampling or justified class weighting.
- [x] Save the best validation checkpoint.
- [x] Evaluate the untouched damage test set.
- [ ] Inspect false-negative damaged eggs.

## Detector

- [ ] Confirm detection labels represent egg presence rather than damage.
- [x] Keep each image paired with exactly one label file.
- [ ] Visually verify or replace the heuristic contour-generated boxes.
- [ ] Retrain the detector on the final static-tray dataset.
- [ ] Evaluate mAP@50, mAP@50–95, precision, recall, false detections per tray,
  missed eggs per tray, and exact tray-count accuracy.
- [ ] Select the production threshold using validation data only.

## Weight calibration

- [ ] Collect paired `length_mm`, `breadth_mm`, and `actual_weight_g`.
- [ ] Use at least 10 eggs for an initial fit; prefer 30–50 or more for release.
- [ ] Fit the calibration coefficient with a reproducible analysis script.
- [ ] Report fitted `k`, R², MAE, RMSE, signed error, and percentage within
  ±3 g.
- [ ] Keep calibration samples separate from the final test set.

## Required reports

- [ ] Damage: accuracy, balanced accuracy, precision, recall, specificity,
  F1, confusion matrix.
- [ ] Cleanliness: the same metrics, with emphasis on stained recall.
- [ ] Detector: mAP, per-tray counts, missed eggs, and false positives.
- [ ] Size: millimeter error and per-class macro F1.
- [ ] Weight: MAE, RMSE, R², and ±3 g rate.
- [ ] End-to-end: exact grade accuracy, reject recall, false-accept rate, and
  complete-tray success rate.
