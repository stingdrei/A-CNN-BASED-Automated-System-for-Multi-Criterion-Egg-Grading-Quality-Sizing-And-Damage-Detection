# T3 — Cleanliness Classifier

## Goal

Add the missing binary cleanliness model for `Clean` versus `Stained`.

## Source audit (2026-10-28)

Two newly added Roboflow COCO datasets were audited:

- `clean eggs/`: 151 images, 365 boxes, classes
  `Brownegg`, `Lightbrownegg`, `Whiteegg`, `color`.
- `Eggs degrading quality/`: 97 images, 506 boxes, classes
  `eggs`, `dirt stained brown egg`, `dirt stained white egg`, `white egg`.

Candidate mapping used by `src/audit_cleanliness_sources.py`:

- Clean: `Brownegg`, `Lightbrownegg`, `Whiteegg` (strong),
  `white egg` from degrading-quality (weak).
- Stained: `dirt stained brown egg`, `dirt stained white egg`.
- Ignore: `color`, `eggs`.

Result: 389 Clean and 481 Stained candidate crops. One exact duplicate image
group and 43 cross-split near-duplicate pairs were found. One invalid COCO box
was found in `Eggs degrading quality/test`.

Evidence:

- `reports/cleanliness_source_audit.json`
- `reports/cleanliness_candidate_crops.csv`
- `reports/cleanliness_source_previews/`

These sources are web/stock imagery with visible watermarks and text overlays.
They are suitable for weak pretraining only, not a locked release test set.
The source splits already contain leakage and must be rebuilt by source image
before training.

## Candidate crop dataset (2026-10-28)

`src/build_cleanliness_dataset.py` builds filtered crop images from the
candidate manifest. It does **not** train a model.

Output: `data/cleanliness_candidates/`

- 608 crops total.
- Train: 425 (195 Clean, 230 Stained), 68 source groups.
- Validation: 92 (42 Clean, 50 Stained), 40 source groups.
- Test: 91 (42 Clean, 49 Stained), 40 source groups.
- Filters: weak `white egg` labels, stock-keyword images, known text overlays,
  crops smaller than 24 px, and duplicate source images.
- Dedupe: exact SHA-256 plus perceptual hash threshold 4; one representative
  source image is kept per duplicate cluster.
- Splits are grouped by source-image cluster. Verified zero cross-split source
  image, SHA-256, source-group, or near-duplicate pairs at threshold 4.

Evidence:

- `reports/cleanliness_candidates_report.json`
- `data/cleanliness_candidates/manifests/{train,valid,test}.csv`
- `data/cleanliness_candidates/README.md`

This is weak pretraining data only. Validation selects the threshold; test is
evaluated once. Physical tray images are still required before release.

Train on a CUDA machine:

```bash
python src/train_classifier.py \
  --labels data/cleanliness_candidates/manifests/train.csv \
  --val-labels data/cleanliness_candidates/manifests/valid.csv \
  --image-root . \
  --output models/egg_grader_cleanliness_v1.pth \
  --metrics reports/cleanliness_crop_resnet18_v1_val_metrics.json \
  --class-names "Clean,Stained" \
  --arch resnet18 --pretrained \
  --stage1-epochs 3 --stage2-epochs 17 \
  --stage1-lr 1e-3 --stage2-lr 1e-4 \
  --batch-size 32 --img-size 224 \
  --select-metric balanced_accuracy \
  --device cuda
```
