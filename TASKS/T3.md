# T3 — Cleanliness Classifier

## Goal

Add the missing binary cleanliness model for `Clean` versus `Stained`.

## Dataset requirements

- [ ] Create:

```text
data/cleanliness/
├── Clean/
└── Stained/
```

- [ ] Collect at least 150 samples per class as a minimum; prefer 500 or more
  per class for the final model.
- [ ] Include dirt, fecal matter, blood spots, glare, shadows, shell-color
  variation, orientation variation, and borderline cases.
- [ ] Define the labeling guide and stain policy.
- [ ] Record annotator and source/session metadata.
- [ ] Measure agreement between at least two labelers on a subset.
- [ ] Split by physical egg or source, not by near-duplicate image.

## Model and training

- [x] Add `src/model_cleanliness.py`.
- [ ] Add a cleanliness manifest generator.
- [ ] Train using the reproducible classifier pipeline.
- [ ] Compare the small CNN with a transfer-learning baseline.
- [ ] Select a validation threshold that protects stained-egg recall.
- [ ] Save a versioned checkpoint with class order and preprocessing metadata.

## Integration

- [ ] Load the cleanliness checkpoint during inference.
- [ ] Run it on each detector crop.
- [ ] Return `cleanliness_status` and `confidence.cleanliness`.
- [ ] Route `Stained` results to `Reject`.
- [ ] Add tests proving stained eggs cannot receive A, B, or C.

## Required metrics

Report balanced accuracy, precision, recall, specificity, F1, confusion matrix,
and confidence calibration on an untouched test set.
